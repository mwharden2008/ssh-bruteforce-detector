# Security and Privacy

- This is a defensive, offline learning project. It reads local text logs only.
- Use it only on files you own or have permission to review.
- `samples/sample_auth.log` is fabricated and contains no real credentials or personal data.
- Never publish production authentication logs or user-specific reports to a public repository.
- `reports/`, unapproved `*.log`, and generated JSON/CSV are ignored by Git by default.
- A threshold alert is a lead for investigation, not confirmation of compromise.
- This code does not replace a SIEM, EDR, or professionally managed incident response.
